# Reverie Collection — AO3 Site Skins

**Reverie Collection** is a family of AO3 site skins built on a shared base with theme variants that each bring their own palette and mood.

The collection currently includes five themes:
- **Pale Reverie** — the original light theme, soft and muted, with a dusty rose and cool slate palette
- **Lucid Dream** — a more vibrant, high-contrast take on the same base
- **Fever Dream** — a dark theme with deep teal and dusty bordeaux
- **Midnight Blues** — a dark theme, muted and melancholic, with olive-tinged shadows and violet accents
- **Counting Stars** — a dark theme, deep and cosmic, with an indigo night sky and blue highlights

## Features

- Color-coded tags by type (warnings, relationships, characters, freeforms)
- Icon-based stats display with hover text labels
- Constellation border around work metadata
- Responsive layout for tablet and mobile
- All colors defined as CSS variables for easy customization
- Theme variants with alternate color palettes

## Installation

See the [AO3 work](https://archiveofourown.org/works/84166896) for full installation instructions.

## Files

| File | Description |
|------|-------------|
| `theme-pale-reverie.css` | **Pale Reverie theme** — light, soft dusty rose and cool slate palette |

| `theme-fever-dream.css` | **Fever Dream theme** — dark, deep teal and dusty bordeaux |
| `theme-midnight-blues.css` | **Midnight Blues theme** — dark, olive backgrounds and muted violet accents |
| `theme-counting-stars.css` | **Counting Stars theme** — dark, deep indigo and blue accents |
| `main.css` | **Base styles** — colors, tags, layout... |
| `tablet.css` | **Tablet skin** — Layout adjustments for tablets (max-width: 62em) |
| `mobile.css` | **Mobile skin** — Minor resets for smaller screens (max-width: 42em) |
